# Capturas da divulgação

Prints datados de cada divulgação do formulário (protocolo, seção 8), um arquivo por envio.

**Nome do arquivo:** `AAAA-MM-DD_canal_integrante.png`, por exemplo `2026-11-13_whatsapp-web_lucas.png`.

**Antes de salvar, confira:**

- A data e a hora do envio aparecem na imagem.
- Nomes, fotos e números de terceiros estão cobertos ou recortados. O enunciado não permite expor dados pessoais nas evidências.
- O link do formulário e o texto da mensagem aparecem na imagem.
